# PokerCalc

Веб-аналог **Flopzilla** с расширенным функционалом. Всё считается в браузере, бэкенда нет.

Ключевые фичи, ради которых проект и строится: **эквити range vs range** и **range morphing** — сужение диапазона по улицам.

## Что умеет

- **Матрица 13×13** с покраской диапазона и весами (25/50/75/100%), отдельно для Hero и Villain
- **Эквити range vs range** — считается в Web Worker, поэтому интерфейс не подвисает. Точный перебор на тёрне/ривере, Monte Carlo на префлопе/флопе
- **Разбор борда** — MADE-категории и дро, с долями от диапазона
- **Range morphing** — сужение диапазона по категориям рук: «оставить только топ-пару и лучше + флеш-дро»
- **Heatmap** — перекраска диапазона по силе рук на текущем борде
- **Ветка событий** — префлоп-спот собирается по шагам, как action tree в GTO Wizard: кто открыл → кто и как ответил → как опенер ответил на 3бет
- **Тренажёр** — тест по префлопу, который спрашивает только по пограничным и смешанным рукам; очевидные вопросы вроде «открываем ли 72o с UTG» не задаются
- Сохранение сценариев в localStorage

## Сравнение диапазонов

Вкладка **«Сравнение»** показывает Hero и Villain рядом. Диапазоны общие с вкладкой «Диапазоны»: можно выбрать префлоп-пресеты там и перейти к сравнению. Борд сравнения и мёртвые карты отдельные; конкретная рука Hero из старого экрана здесь не подменяет диапазон.

- Две редактируемые матрицы, покраска перетаскиванием, веса 1–100%, копирование диапазона соперника.
- Ввод и экспорт строкой: `QQ+, AJs+, KTs-KQs:50, AhKd`. Вес после двоеточия — процент. Интервалы непарных рук имеют общий старший ранг; последнее вхождение заменяет вес. Экспорт сохраняет веса отдельных комбинаций.
- Эквити, победы и ничьи; точный перебор до 200 тысяч раскладов, иначе Monte Carlo с выборкой 80 тысяч / 300 тысяч / 1 миллион. Изменение входов отменяет предыдущий расчёт.
- Сопоставление готовых рук и дро: проценты и взвешенные комбо от исходных диапазонов после блокеров. Нажатие категории включает независимый фильтр для выбранной стороны. Категории объединяются по «ИЛИ», исходные веса сохраняются.
- График эквити отдельных комбо, таблица с весами, победами, ничьими и числом наблюдений; окраска матриц по эквити. В Monte Carlo редкие комбинации имеют мало наблюдений, а ненаблюдавшиеся не показаны.
- **Hotness** по запросу: эквити после каждой следующей карты на флопе/тёрне. Текущие отфильтрованные диапазоны фиксированы, блокеры следующей карты учитываются. До 20 тысяч раскладов — точно, иначе 10 тысяч симуляций на карту.
- «Сохранить» сохраняет оба диапазона, карты и фильтры сравнения. Старые сохранения поддерживаются. Фильтры сохраняются при переключении вкладок; «Сброс» очищает сценарий.

Это инструменты для сравнения двух диапазонов, а не полная совместимость с Flopzilla Pro: мультивей, импорт его файлов, библиотека именованных диапазонов и редактор отдельных мастевых комбо в матрице пока не реализованы (комбо можно задавать строкой).

## Стек

Vite 6 + React 19 + TypeScript + Tailwind v4 + Zustand. Тесты — Vitest.

## Команды

```bash
npm install
npm run dev        # дев-сервер → http://localhost:5173
npm test           # vitest
npm run typecheck  # tsc без сборки
npm run build      # прод-сборка
```

## Устройство

```
src/
  engine/      чистая логика, без React
    cards.ts        карта = int 0..51 (rank*4 + suit)
    combos.ts       1326 комбо, 169-hand ярлыки, сетка 13×13, класс Range
    evaluator.ts    7-карточный эвалуатор → сравнимое int
    categorize.ts   MADE-категории и дро, морфинг диапазона
    equity.ts       точный перебор либо Monte Carlo
  workers/       эквити вне UI-потока
  state/         Zustand-стор
  presets/       префлоп-чарты, дерево линий, генератор вопросов тренажёра
  ui/            React-компоненты
tools/           python-скрипты оцифровки PDF-чартов
```

Диапазон — `Float32Array` на 1326 комбо с весом 0..1. Мутируется на месте, поэтому в сторе есть счётчик `rev`, который инкрементится при любом изменении: на него подписаны компоненты, иначе React не перерисует.

Эквити валидировано по эталонам: AA vs KK ≈ 82%, AKs vs QQ ≈ 46%.

Подробности архитектуры и гочи — в [CLAUDE.md](CLAUDE.md).
